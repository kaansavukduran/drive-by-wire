## Yeniden üretim ve kanıt

```sh
bash tests/run_all.sh
python3 packaging/build_web.py
python3 -m http.server 8765 --directory build/web
node tests/browser_forge.cjs
node tests/browser_book.cjs
node tests/browser_appearance.cjs
node tests/browser_loading.cjs
node tests/browser_quality.cjs
node tests/browser_smoke.cjs
node tests/browser_settings.cjs
```

Playwright test aracıdır; runtime bağımlılığı değildir. NODE_PATH/DBW_CHROMIUM mevcut kuruluma göre verilir. Testler ?qa salt okunur snapshot'ları kullanır. Gerçek klavye/fare/CDP touch/navigator.getGamepads girdileri gider; oyun değerlerine yazan test API'si eklenmez. Fizik simülasyonunda sabit tohum kullanılır; bu fiziksel cihaz veya insan oyun testi diye sunulmaz. Nihai ölçümler, loglar ve PNG'ler doğrulama paketindedir.

Ölçüm açılışı normal 3014 ms / düşük güç 1827 ms; önbellek etkisi olabilir, internet performansı karşılaştırması değildir. CDP JS heap 11.8 / 9.8 MB yalnız JS kısmıdır; WASM/GPU/toplam değildir. Testte üçüncü taraf istek listeleri ve runtime hata listeleri boştu.

**Görsel yayımlama durumu:** Çilekli yükleyici yerelde test edildi. Özel Drive JPG’sinin public GitHub/önizlemeye aktarımı otomatik onay denetimince açık paylaşım izni olmadığı için reddedildi. İzin beklenirken kamuya açık kaynak/önizleme yalnız Fragaria marka yazısını gösterir; JPG ve onu içeren yükleme ekranı görüntüsü bu kaynağa dahil edilmez. 13 son ve diğer oyun özellikleri bundan etkilenmez.

Public test ekranı yüklemesi de otomatik onay denetimince hedefe açık görsel paylaşım izni olmadığı için reddedildi. Bu ekranlar kaynak ağacına ve public PR’a dahil edilmez; yerel kanıtta korunur. Oyun simgeleri kullanıcı talebiyle oluşturulan özgün İLİN oyun varlıklarıdır.

**Uzak yayın durumu:** v0.6 kaynak ağacının gönderimi, içerdiği özel referans bağlantıları/varlık kapsamı nedeniyle otomatik onay denetimince ayrıca reddedildi. GitHub dalı/PR ve uzak oyun önizlemesi bu sürüme güncellenmedi. Wordmark fallback temiz kaynak ağacında yerelde derlendi ve web smoke PASS; bu uzak yayın başarısı değildir. Çilekli tam sürüm ve görsel kanıtlar yalnız yerel teslimde bulunur. Dışarı aktarma için kaynak, referans bağlantıları ve görselleri kapsayan açık hedef onayı beklenir.
